# ClipCutter

Find the kills and big moments in your videos and export ready-to-post Shorts and Reels, all inside your browser (nothing is uploaded).

- Open the site: https://dharmadr.github.io/Google/
- How it works, history and ideas: see `PROJECT.md`
- New in v5: method "Main-player kills only" (only your kills, no filler clips) and a separate **Montage** page (`montage.html`) that joins finished clips into one video with per-clip trimming.
