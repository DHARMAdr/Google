Teach it my name

  1. Move the slider to a moment where your kill is shown in the kill feed.
  2. Drag a box around your own name in that kill-feed line (include your agent/character icon if it is next to it). Keep it tight, only your name.
  3. Press Save. From now on "Find my highlights" looks for that name and makes Shorts only from those lines.

Your server

The server is a small free Cloudflare "storage" of your own. It keeps your videos and Shorts under your profile and gives them back if this device forgets them. Without it everything still works, but only on this device.

  1. Make a free account at dash.cloudflare.com. Open Storage & databases > R2 and create a bucket (any name, for example clipcutter).
  2. Open Workers & Pages > Create > Worker, name it, press Deploy, then Edit code.
  3. Delete the sample code, press Copy the server code here, paste it into the editor, press Deploy.
  4. Settings > Bindings > Add > R2 bucket: variable name BUCKET, choose your bucket.
  5. Settings > Variables and Secrets: add a Secret named TOKEN (a long password only you know) and a text variable ALLOWED_ORIGINS =
  6. Deploy again, copy the worker address (ends with .workers.dev), paste it above and press Check server. All lines must say OK.
  7. Back in Profile: type a username and a 6-digit code. For the first (admin) profile open "Creating the ADMIN profile" and enter your TOKEN as the owner key.
